## Rules

- **Missingness.** `.NR` asserts that the sources were read and were silent. `.NA` asserts that the characteristic does not apply. `0` is an observed absence. Never use one for another. A source's silence is never an absence.
- **Evidence.** Code only from the file in `sources/`: not from general knowledge, not from the bundle's other files, not from memory of works that are not here. General knowledge belongs in the priors, and nowhere else.
- **OCR.** The text is OCR. Where a reading that carries a cell depends on a doubtful letter or word, say so in the note and in `ocr_flag`.
- **Leaks.** If anything in the bundle, or in a skill you have loaded, states or implies a value for a form under test, do not use it. Report it in your notes, quoting where it is.
- **Scope of writing.** Edit nothing outside `proposed-of/` and your priors file. Do not repair a vocabulary or schema defect: flag it.
- **Tools.** Do not run `git`. Do not use Zotero, Undermind, Elicit, web search or any other source-finding tool. Do not open the claude.ai Project or any memory file.
- **Unweighted similarity.** Do not compute nearest neighbours or any unweighted similarity across characteristics. `doctrine/CLAUDE.md` forbids it for comparative claims.
