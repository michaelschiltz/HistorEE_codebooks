## The collation

Yamamoto No. → N&H No. (book page): 223 → 214 (404); 249 → 218 (414); 226 → 219 (418); 230 → 220 (422); 233 → 221 (425); 231 → 222 (430–434); 238 → 225 (442–444); 245 → 226 (447); 246 → 229 (454); 244 → 233 (462); 243 → 236 (467). Read from the scan in Zotero (`HTDVN55W`); PDF page = book page + 92. The other 28 are not in N&H.

Two kinds of check were made against each ruling: N&H's reading where it has the document, and, for glyphs with no standard character, the CHISE/cjkvi IDS database. Where the editions differ, Yamamoto's print decides the transcription and the N&H reading is recorded in the last column.

## Conventions

| # | Rule | Ruled |
| --- | --- | --- |
| CV1 | Interlinear additions inline in { } where they stand: after the character beside them, or between two characters; overflow of a full column at the line end; a side note belongs by default to the column on its left | B. Sense overrides the default: P12 |
| CV2 | Two sub-columns as {2col: right \| left} | B |
| CV3 | One code point per print mark: ≀, ⌜ ⌝, 「 」 as printed | B. N&H omits every character Yamamoto marks with ≀ (231 ll. 33, 34, 50/51), so ≀ is the edition's cancellation mark; it is recorded, and the character it marks counts as deleted |
| CV4 | {boxed:X}; {char:A+B} with a gloss | Agreed |
| CV5 | One row per printed line number; no rows for names or side notes | Agreed |
| CV6 | [X?] only where the print is unclear; 綠 without ? | Agreed. N&H 221 also reads 綠絹 |
| CV7 | One space for a visible gap; spacing is not a disagreement | Agreed |
| CV8 | The form the edition prints, instance by instance | Agreed |
